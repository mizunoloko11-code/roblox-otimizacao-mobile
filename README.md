## 📋 Descrição

Script de otimização mobile leve e eficiente para Roblox, com interface limpa e intuitiva. Reduz lag, remove texturas desnecessárias e otimiza a conexão para melhor desempenho em celulares.

---

## ⚙️ Funcionalidades

✅ **Otimização Geral** - Remove texturas, reduz efeitos e melhora desempenho geral

🎮 **Otimização Campo** - Remove linhas/marcações do campo e reduz lag

⚪ **Bola Branca** - Bola totalmente limpa em cor branca pura

🔴 **Bola Vermelha** - Bola totalmente limpa em cor vermelha pura

📡 **Ping Reduzido** - Otimiza conexão e reduz a latência de rede

## 🛠️ Solução de Problemas

**❌ GUI não aparece?**
- Tente carregar novamente o script
- Verifique se você está em um jogo Roblox ativo
- Reinicie o executor

**❌ Script não funciona?**
- Certifique-se que o executor está funcionando
- Tente outro executor (KRNL, Synapse, Fluxus, etc.)
- Verifique a conexão com a internet

**❌ Otimizações não funcionam?**
- Alguns jogos podem ter proteções contra scripts
- Ajuste as opções individualmente
- Tente um jogo diferente para testar

**❌ Erro ao carregar com LoadString?**
- Verifique se seu executor permite HttpGet
- Verifique sua conexão com a internet
- Copie o código manualmente do repositório
